Quick Install (Recommended)

The easiest way to install Docker on most Linux systems:

1 Download and run the official Docker install script:
curl -fsSL https://get.docker.com -o get-docker.sh sudo sh get-docker.sh
2 Add your user to the docker group (so you don't need sudo):
sudo usermod -aG docker $USER newgrp docker
3 Verify Docker is running:
docker --version docker ps

If you see version info and no errors, Docker is ready!

Manual Installation

If you prefer manual installation, choose your distribution:

  • Ubuntu/Debian: Docker Installation Guide
  • CentOS/RHEL: Docker Installation Guide
  • Fedora: Docker Installation Guide
  • Other Linux: Docker Documentation

WSL (Windows Subsystem for Linux)

If you're running WSL on Windows, install Docker Desktop for Windows:

  • Download from Docker Desktop
  • Enable WSL 2 integration in Docker Desktop settings
  • Restart WSL after installation

Next Steps

After installing Docker:

  1. Make sure Docker service is running: sudo systemctl status docker
  2. Refresh this page to continue with StackArr setup
